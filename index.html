Projects

ISPOS: Intelligent Solar Panel Orientation System

Jan – Apr 2025
Graduate capstone, Northeastern University · Advisors: Dr. Rolando Herrero, Dr. Haitham Tayyar

A system that decides how to point a solar panel by combining three inputs: sun detection from an ESP32-CAM camera, sun-position calculations (PVLib) and live weather data (Open-Meteo), so that it adjusts to clear or cloudy skies. Monitoring runs over ESP32, LoRa and MQTT to a ThingsBoard dashboard on AWS EC2. I also built a 10-year hourly dataset for Toronto (about 87,700 records) combining sun position and weather, used it to study how seasons and cloud cover affect solar potential, and compared four sun-position libraries (PVLib, Skyfield, Ephem, PySolar) for accuracy. In the prototype, orientation decisions are shown on LED indicators; a motorised mount is the next step.

MQTT-Based Industrial Telemetry and Real-Time Dashboard

2026
Independent technical project

A containerised pipeline that simulates temperature readings from several production lines and sends them through a Mosquitto MQTT broker using Python, with organised topics for each line and wildcard subscriptions. A Node-RED flow parses the JSON messages and displays live telemetry on a dashboard, with Mosquitto and Node-RED running in separate Docker containers on a shared network.
