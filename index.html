01 Solar energy · Sensor fusion · IoT

ISPOS: Intelligent Solar Panel Orientation System

A hybrid sun-tracking system that combines ESP32-CAM brightness detection with PVLib sun-position calculation and live Open-Meteo weather data. Weather-aware decision logic trusts the astronomical model under clear skies and the camera under cloud, then sends orientation commands to the ESP32 over LoRa, with telemetry on ThingsBoard (AWS EC2) via MQTT.

Alongside it I benchmarked four solar-position libraries and built a 10-year hourly Toronto dataset (about 87,700 records) merging sun position with weather, which I'm now using for solar-availability forecasting. Master's capstone, Jan–Apr 2025.

ESP32-CAMLoRaMQTT ThingsBoardAWS EC2Python PVLibSkyfieldPySolarOpen-Meteo

Problem
Fixed panels miss available yield, and commercial trackers are costly and don't adapt to cloud cover.
Results
Solar-position libraries agreed within ±0.3° to ±0.7°. Decision logic and LoRa command link working end to end.
Prototype status
Orientation decisions shown on an LED indicator; motorised mount not yet built.

03 Industrial IoT · Messaging · Building automation

Industrial Telemetry Pipeline over MQTT

Python Paho publishers stream equipment telemetry through a Mosquitto broker using a hierarchical topic structure. Wildcard subscriptions feed a Node-RED dashboard, and each service runs in its own Docker container. It mirrors the messaging patterns used in industrial IoT and building automation.
